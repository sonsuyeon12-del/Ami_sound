# 아미를 듣다 — 나의 아미 사운드

아미미술관에서 QR로 접속해 사용하는 모바일 웹 프로그램 프로토타입입니다.

## 구성
- 소리 목록을 미리 보여주지 않고 관람객이 직접 소리를 채집
- 3초씩 3~5개의 소리를 녹음
- 조합 화면에서 낙엽 애니메이션
- 녹음한 실제 소리를 Web Audio API로 변환/레이어링
- 약 10초의 개인 사운드 생성
- 결과 화면에서 관람 중 귀 기울인 방향을 간단히 해석

## 중요
현재 버전은 녹음된 소리를 서버로 보내지 않고 브라우저 안에서만 처리합니다.
자동 음향 분류 AI는 아직 넣지 않았습니다. 초기 운영 테스트에서 실제 관람객이 어떤 소리를 채집하는지 확인한 뒤 분류 모델을 붙이는 것을 권장합니다.

## GitHub Pages
index.html을 저장소 루트에 올린 뒤 Settings → Pages에서 배포하면 됩니다.
GitHub Pages는 HTTPS를 지원하므로 마이크 권한을 사용하는 웹앱에 사용할 수 있습니다.
